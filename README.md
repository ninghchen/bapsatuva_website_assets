# BAPS @ UVA Website Assets

This repository contains website assets for the **Become a Problem Solver (BAPS) at the University of Virginia** website.

These assets are used to support the design and development of the BAPS @ UVA website, including images, logos, graphics, and other media.

## Website

Visit the BAPS @ UVA website at **bapsatuva.org**.

## Repository Contents:

* BAPS @ UVA logos
* Event and organization photos
* Website graphics
* Icons and branding elements
* Other media used throughout the website

## Usage

Assets in this repository are intended primarily for use on the official BAPS @ UVA website and related organization materials.
